Ceridwen: SSP Grids to Composite Spectra

This layer converts precomputed single-age spectra into one composite galaxy spectrum. Read “grid” as stored numerical values and “basis” as the algorithm that weights and combines them.

SSP containers

SSPData stores four arrays:

  • ssp_lgmet: (n_met,), log10 absolute metallicity.
  • ssp_lg_age_gyr: (n_age,), log10(age/Gyr).
  • ssp_wave: (n_wave,), Angstrom.
  • ssp_flux: (n_met, n_age, n_wave), L_sun/Hz/M_sun.

The contract and shape check are at ceridwen/ceridwen/ssps/ssp_data.py:206-279. HDF5 loading is at lines 402-443; FSPS grid generation is at lines 448-534.

SSPDataAfe adds a leading composition axis:

  • ssp_afe: (n_afe,), [alpha/Fe] dex.
  • ssp_flux: (n_afe, n_met, n_age, n_wave).

Its exact contract is at ssp_data_afe.py:70-130. A legacy three-dimensional grid is promoted to one solar-alpha plane during loading (lines 234-280).

ceridwen/ceridwen/ssps/ssp_data.py:269-279

The tuple on the right defines the axis contract. The flux cube must align exactly with the metallicity, age, and wavelength coordinate arrays.

Available grids

  • MIST+MILES, Chabrier, solar-scaled.
  • BPASS binary SSPs, Chabrier.
  • aMIST+C3K low-resolution, Chabrier, five alpha planes.
  • aMIST+C3K null control, currently unpublished.

CSP construction

CSPBasis consumes a three-dimensional SSPData; CSPBasis_afe requires a four-dimensional SSPDataAfe. The alpha basis checks the leading axis and rejects an incompatible grid at csp/csp_afe.py:318-353.

A CSP construction establishes static structure:

  • increasing lookback-time nodes, today to oldest;
  • an SFH value per node or bin;
  • constant Z or time-varying zh;
  • enabled dust, nebular, IGM, and smoothing components.

CSPBasis.initialize_model_structure validates this contract at csp/csp.py:522-710. Z and zh are both log10 absolute metallicity, not [Z/H] and not log10(Z/Z_sun) (csp/csp.py:1774-1802).

From SFH parameters to weights

The notebooks sample consecutive SFR log-ratios. The transform:

logsfr_ratios
      |
      v
cumulative log SFR -> linear SFR -> unit-mass normalization
      |
      v
theta["sfh"]

logsfr_ratios_to_sfh implements this at ceridwen/ceridwen/model/transforms.py:79-169. The CSP weight kernel then integrates that SFH over SSP age cells and interpolates metallicity (csp/csp.py:1774-1946). Thin wrappers select constant/time-varying metallicity and linear/step SFH behavior (lines 1948-1981).

ceridwen/ceridwen/model/transforms.py:142-167

ratios  = jnp.asarray(logsfr_ratios, dtype=float)            # (n-1,)
# Anchor log10(SFR[0]) = 0, then cumulate the negative ratios
log_sfr = jnp.concatenate([jnp.zeros(1),
                            -jnp.cumsum(ratios)])             # (n,)
sfr     = 10.0 ** log_sfr                                     # (n,)

if sfh_times_yr is not None:
    times = jnp.asarray(sfh_times_yr, dtype=float)            # (n,)
    dt    = jnp.abs(jnp.diff(times))                          # (n-1,)
    # Standard trapezoidal quadrature weights (yr):
    #   w[0]   = 0.5 * dt[0]
    #   w[i]   = 0.5 * (dt[i-1] + dt[i])   for 0 < i < n-1
    #   w[n-1] = 0.5 * dt[n-2]
    w_lo  = jnp.concatenate([jnp.zeros(1), dt])               # (n,)
    w_hi  = jnp.concatenate([dt, jnp.zeros(1)])               # (n,)
    w     = 0.5 * (w_lo + w_hi)                               # (n,)
    # Unit-mass normalisation: ∫SFR dt = sum(sfr * w) = 1 Msun.
    # GOTCHA: normalise to total mass, NOT mean SFR — dividing by
    # sum(w) instead would leave an implicit factor of t_universe[yr]
    # (~1.4e10) in the spectrum and bias every logmass estimate by
    # ~10 dex at z=0 (less at higher z).
    total_mass = jnp.sum(sfr * w)
    sfh   = sfr / total_mass
else:
    # Discrete fallback: sum(sfh) = 1.
    sfh = sfr / jnp.sum(sfr)

The first five lines reconstruct relative SFR values. The branch then normalizes either a time integral or a discrete sum, so the later logmass parameter controls total amplitude.

Alpha interpolation

CSPBasis_afe._afe_coords finds the bracketing alpha planes and interpolation weight (csp/csp_afe.py:823-846). _flux_at_afe reads only those two planes and linearly interpolates them (lines 848-878). A one-plane grid compiles this operation away.

ceridwen/ceridwen/csp/csp_afe.py:870-878

if self._n_afe == 1:
    return self.flux[0]
if "afe" not in theta:
    return self.flux[self._afe_solar_idx]
k, w = self._afe_coords(theta)
f_lo = jnp.take(self.flux, k - 1, axis=0)
f_hi = jnp.take(self.flux, k,     axis=0)
w32  = w.astype(jnp.float32)
return (jnp.float32(1.0) - w32) * f_lo + w32 * f_hi

The two early returns handle static special cases. The general path gathers only the lower and upper alpha planes, then linearly blends them with w.

Spectrum and prediction

The weight calculation produces coefficients over metallicity and age. Those coefficients combine the SSP flux cube into a rest-frame spectrum; enabled physics modifies it. predict then applies mass, distance/redshift, and IGM scaling before projecting it into observation space (csp/csp.py:1110-1174, 1219-1338).

CSPBasis_afe has no nebular model. It returns a zero line component and rejects line observations (csp/csp_afe.py:1096-1177).
