Ceridwen Architecture

Ceridwen is a JAX-native stellar-population forward model and Bayesian fitting package. Its package root exposes SSPData, CSPBasis, SedModel, and fitSED (ceridwen/ceridwen/__init__.py:30-44).

Package map

  • ssps/: load, generate, validate, and fetch SSP grids.
  • csp/: combine SSP spectra into a galaxy spectrum.
  • dust/, neb/, igm.py: optional physical components.
  • observation/: measured data and model-to-data projections.
  • model/: parameter bookkeeping, transforms, priors, prediction.
  • likelihood/: noise models and data-model comparison.
  • sampler/: priors, adapters, NUTS, nested sampling, and VI.
  • cosmology.py: differentiable distances, ages, and flux factors.
  • fit.py: high-level orchestration and result serialization.

Package __init__.py files show the intended public surface. Start there before opening implementation modules.

Fit paths

fitSED is the high-level route. It builds default diagonal likelihoods, selects a sampler adapter, runs it, writes HDF5, and logs configuration and timings (ceridwen/ceridwen/fit.py:67-282).

run_sampler is the lower-level route. The notebooks use it because they build custom MultiObservationLikelihood and DiagonalNoiseModel objects directly (ceridwen/ceridwen/sampler/runner.py:275-366).

Static versus sampled state

Static at model construction:

  • SSP grid axes and flux cube.
  • SFH grid length and observation types.
  • Filter curves, pixel wavelengths, and projection matrices.
  • Enabled physics components and likelihood structure.

Changed at each sampler step:

  • Free parameter arrays in theta.
  • Derived parameters computed by transforms.
  • Spectrum, projected predictions, likelihood, and prior values.

Static structure lets JAX compile one numerical graph. Changing shapes, observation types, or dict keys usually requires a new trace.

ceridwen/ceridwen/model/model.py:287-292

if not self.transforms:
    return free_theta
model_theta = dict(free_theta)
for derived_param, fn in self.transforms.items():
    model_theta[derived_param] = fn(free_theta)
return model_theta

Transforms add derived values to a copy. Free sampler parameters stay present, while keys such as sfh are calculated before the CSP sees the dictionary.
