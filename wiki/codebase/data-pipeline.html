Raw catalogues

data/raw/borghi2022/vizier_J-ApJ-927-164_table4.tsv contains 140 unique galaxies with published ages, [Z/H], [alpha/Fe], coordinates, and errors. It lacks redshift, velocity dispersion, and indices (data/raw/borghi2022/README.md).

data/raw/legac_dr2/legaCdr2.fits.gz contains 1,988 spectrum rows. It supplies redshifts, velocity dispersions, Lick indices, flags, coordinates, and a spectrum filename. Repeat observations mean object ID is not unique (data/raw/legac_dr2/README.md).

data/raw/cosmos2015/ contains positional matches used for NUVrJ selection and broadband fluxes. Catalogue rows are matched to LEGA-C spectrum rows, so repeat objects can occur (data/raw/cosmos2015/README.md).

Joined Borghi and LEGA-C tables

The builder parses and validates exactly 140 Borghi IDs (scripts/build_borghi2022_legac_dr2_subset.py:109-122). It indexes every LEGA-C row by OBJECT (lines 194-204), retains all matching spectrum rows, and confirms every coordinate match lies within 0.1 arcsec (lines 209-264).

The result contains 143 spectrum rows for 140 galaxies. Two repeat-spectrum objects cross the strict 215 km/s boundary and are explicitly marked ambiguous in the object audit (data/processed/borghi2022_legac_dr2/README.md).

Spectrum files

Each LEGA-C FITS file stores one binary-table row whose cells hold arrays:

  • WAVE: observed-frame air wavelength in Angstrom.
  • FLUX, ERR: 10^-19 erg s^-1 cm^-2 Angstrom^-1.
  • QUAL: nonzero bad-pixel flag.

The downloader checks exactly these columns and the single-row structure (scripts/download_legac_dr2_spectra.py:64-79). Notebook 07 converts air to vacuum wavelengths and F_lambda to F_nu before creating a Ceridwen Spectrum under headings “Load the same high-S/N test galaxy” and “Build the native-resolution spectrum.”

Photometry

The photometry downloader queries within one arcsecond, computes separations, sorts by LEGA-C index and separation, and retains the nearest candidate (scripts/download_cosmos2015_legac_dr2_photometry.py:61-99). The selected aperture fluxes are microJy (lines 110-113). Notebook 06 converts microJy to AB maggies and adds a five-percent uncertainty floor under “Build the twelve-band photometric observation.”

Data contracts entering Ceridwen

  • Photometry.flux: one-dimensional AB maggies.
  • Photometry.uncertainty: same shape and units.
  • Spectrum.wavelength: observed-frame vacuum Angstrom.
  • Spectrum.flux: observed F_nu compatible with model prediction.
  • Spectrum.mask: True where a pixel participates in the likelihood.

The base observation validates one-dimensional aligned arrays and masks non-finite flux or non-positive uncertainty (ceridwen/ceridwen/observation/base.py:171-213).

rows_by_id: dict[int, list[int]] = defaultdict(list)
for index, object_id in enumerate(dr2["OBJECT"]):
    rows_by_id[int(object_id)].append(index)

missing_ids = [
    int(row["[MMS2013]"].strip())
    for row in borghi_rows
    if not rows_by_id[int(row["[MMS2013]"].strip())]
]
if missing_ids:
    raise ValueError(f"Borghi IDs missing from LEGA-C DR2: {missing_ids}")

output_rows: list[dict[str, str | int]] = []
separations: list[float] = []

for borghi in borghi_rows:
    object_id = int(borghi["[MMS2013]"].strip())
    match_indices = sorted(
        rows_by_id[object_id], key=lambda i: str(dr2["SPECT_ID"][i])
    )

rows_by_id maps one galaxy ID to a list, not one row. That single type choice explains how repeat spectra survive the join.

order = np.lexsort(

candidates = candidates[order]
_, nearest = np.unique(
    np.asarray(candidates["LEGAC_INDEX"]), return_index=True

Sorting groups candidates by LEGA-C row and then by separation. np.unique(..., return_index=True) therefore selects the nearest candidate in each group.
