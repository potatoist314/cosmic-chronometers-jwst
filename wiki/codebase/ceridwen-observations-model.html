Ceridwen: Observations and SedModel

Observations define measured data space. SedModel connects those data containers to the CSP forward model and decides which parameters are sampled.

Observation contract

Every Observation stores:

  • flux: one-dimensional measured values.
  • uncertainty: one-dimensional one-sigma errors.
  • mask: boolean, True means included.
  • name: unique key used in prediction dictionaries.

Construction and conversion to JAX arrays occur at ceridwen/ceridwen/observation/base.py:59-89. rectify checks shapes and automatically masks invalid values (lines 171-213).

A fluxless observation is allowed for forward prediction, provided its filters or wavelength grid are known (base.py:176-184).

ceridwen/ceridwen/observation/base.py:186-198

assert self.flux.ndim == 1,        "flux must be 1-D"
assert self.uncertainty is not None, "uncertainty is required when flux is provided"
assert self.uncertainty.ndim == 1, "uncertainty must be 1-D"
assert len(self.flux) == len(self.uncertainty), \
    "flux and uncertainty lengths differ"

if self.wavelength is not None:
    assert self.wavelength.ndim == 1, "wavelength must be 1-D"
    assert len(self.wavelength) == len(self.flux), \
        f"wavelength length ({len(self.wavelength)}) ≠ flux length ({len(self.flux)})"

self._automask()
assert self.ndof > 0, "no valid unmasked data points after masking"

Read the assertions as a data contract: aligned one-dimensional arrays enter, automatic masking runs, and at least one usable datum must remain.

Projection contract

setup_for_model(wave_model) performs static work before JIT. predict performs only the numerical projection used at each model evaluation (base.py:249-301). SedModel.__init__ calls setup automatically for every observation (model/model.py:197-211).

Photometry

Photometry stores AB maggies, where one maggie is 3631 Jy (observation/photometry.py:19-46). It converts model F_nu to F_lambda and integrates filter transmission (lines 117-151). Its prediction has one value per filter.

ceridwen/ceridwen/observation/photometry.py:264-266

if getattr(self, "_has_precomputed_T", False):
    return self._T @ spectrum
return self.get_maggies(wave_model, spectrum)

The fast path is one matrix-vector multiply. The fallback performs the same filter projection without a precomputed matrix.

Spectrum

Spectrum.setup_for_model maps the model wavelength grid onto observed pixels. With no smoothing it builds a dense interpolation matrix _H; with smoothing it builds a JAX-compatible closure for LOSVD and instrumental response (observation/spectrum.py:243-491). predict calls that prepared closure and returns one model value per observed pixel (lines 493-557).

ceridwen/ceridwen/observation/spectrum.py:543-557

if self.fit_sigma_smooth:
    if sigma_smooth is None:
        # Fall back to the constructor default; lets a caller
        # invoke ``predict(spec, wave)`` for warmup / debugging
        # even when the closure is the runtime-sigma variant.
        sigma_smooth = self.sigma_losvd
    # Pass sigma through without forcing a dtype -- JAX's
    # dtype-promotion rules with jax_enable_x64=True will
    # promote to float64 to match the cached smoother grids,
    # giving the same precision the static fast path achieved.
    # Forcing float32 here would round-trip-degrade the smoother
    # output even when the user is fitting in double precision.
    sv = jnp.asarray(sigma_smooth).reshape(())
    return self._predict_fn(spectrum, sv)
return self._predict_fn(spectrum)

Both branches call the closure prepared during setup. Only the fitted-velocity branch passes a traced smoothing parameter.

Lines

Lines represents continuum-subtracted emission-line fluxes. The solar-scaled CSPBasis can predict them from nebular grids; CSPBasis_afe cannot because it has no nebular component.

SedModel parameter bookkeeping

SedModel.__init__ starts from csp.theta_init, then removes parameters that will be derived by transforms and adds replacement free parameters (model/model.py:141-195). It owns:

  • theta_init: starting arrays for free parameters.
  • param_names: ordered free-parameter names.
  • priors: probability distributions on free parameters.
  • transforms: free-to-derived calculations.
  • observations: projection targets.

Example from notebooks 06-08:

free: logsfr_ratios, Z, afe, logmass, diffuse_tau_kc
                         |
                         +-- transform --> sfh
fixed/derived: diffuse_dust_index, sometimes lookback_time

One prediction

SedModel.predict(theta):

  1. Applies every transform (model/model.py:263-292).
  2. Injects fixed redshift when it is not sampled (lines 334-348).
  3. Calls csp.predict(model_theta, observations) (line 351).
  4. Receives a dict keyed by unique observation names.

predict_jit caches compilation for one parameter-tree structure; predict_vmap adds a leading sample dimension for posterior predictions (model/model.py:357-402).

ceridwen/ceridwen/model/model.py:345-351

if self._zred_fixed is not None and "zred" not in model_theta:
    if model_theta is theta:          # apply_transforms may not copy
        model_theta = dict(model_theta)
    model_theta["zred"] = self._zred_fixed
# Mass scaling is handled inside csp.predict() — the spectrum is
# scaled once before projection, rather than per-observation.
return self.csp.predict(model_theta, self.observations)

A fixed redshift is inserted only when the sampled dictionary lacks one. The final line returns a dictionary whose keys are observation names.

Shapes and units

  • Scalar free parameters are usually stored as shape (1,) arrays.
  • logsfr_ratios has shape (n_sfh_bins - 1,).
  • A prediction dict value matches its observation length.
  • logmass is log10 formed stellar mass in solar masses.
  • Z is log10 absolute metallicity.
  • afe is [alpha/Fe] dex.
  • zred is dimensionless.
