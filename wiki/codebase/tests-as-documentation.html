Tests as Documentation

Tests show which behavior maintainers consider contractual. They are often a faster introduction than long implementation files because inputs and expected outputs appear together.

The root Astro project currently has no project-owned tests/ directory. Ceridwen has focused unit, misuse, regression, and grid-dependent tests.

Test map

Constructing a CSP

Read ceridwen/tests/test_csp_construction.py beside ceridwen/ceridwen/csp/csp.py:522-710.

It demonstrates:

  • the lookback_time= shortcut;
  • node-based versus per-bin SFH shapes;
  • constant versus time-varying metallicity;
  • errors for missing structure or one-node grids.

Predictive observations

Read ceridwen/tests/test_observation_predictive.py beside observation/base.py:171-184 and observation/spectrum.py:243-308.

It proves a fluxless spectrum can preserve its wavelength grid, prepare a projection, and generate model values.

SSP provenance

Read ceridwen/tests/test_ssp_provenance.py beside ssps/ssp_data.py.

It covers HDF5 metadata round trips, legacy grids, prohibited FSPS parameters, and automatic isochrone propagation into the CSP.

Redshift-dependent ages

Read ceridwen/tests/test_zred_age_tracking.py beside csp/csp.py:1748-1772.

Its tests check that the oldest SFH bin tracks universe age, the spectrum changes, gradients flow through redshift, and the fixed-redshift path remains unchanged.

Observation projection and noise

  • test_spectrum_fixes.py: LSF input resolution, calibration, line masking.
  • test_lines_static.py: static line-projection matrix and JIT behavior.
  • test_line_projection_continuum.py: continuum-subtracted nebular lines.
  • test_upper_limit_likelihood.py: detections versus upper limits and gradients.
  • test_losvd_no_lyman_spike.py: FFT smoothing boundary regression.

Physical invariants and misuse

ceridwen/tests/regression/test_misuse.py checks shared units across SSP weight calculations, finite zero-SFR behavior, emission-line scaling semantics, and unknown parameter keys. tests/csp/test_lookback_flip_invariant.py checks that time-order conventions do not silently change the physics.

Examples

ceridwen/tests/test_csp_construction.py:48-61

def test_shortcut_matches_full_theta_structure(ssp):
    lb = jnp.linspace(0.0, 12.0, 6)
    via_theta = CSPBasis(
        ssp, theta={"lookback_time": lb, "sfh": jnp.ones(6),
                    "Z": jnp.array([-1.85])}, **KW)
    via_shortcut = CSPBasis(ssp, lookback_time=lb, **KW)

    np.testing.assert_allclose(np.asarray(via_shortcut.sfh_times),
                               np.asarray(via_theta.sfh_times))
    assert via_shortcut.n_time == via_theta.n_time == 6
    assert via_shortcut.sfh_per_bin is False
    assert via_shortcut.zh_is_scalar is True          # zh_const -> 'Z' mode
    # Neutral initial Z must lie inside the grid: no clamp messages.
    assert via_shortcut.check_param_ranges(warn=False) == []

Two construction routes receive equivalent inputs. Every assertion names one part of “equivalent”: grid, node count, SFH representation, metallicity mode, and range validity.

ceridwen/tests/test_observation_predictive.py:35-47

def test_fluxless_spectrum_setup_and_predict():
    wave_obs = np.linspace(4000.0, 8000.0, 50)
    spec = Spectrum(wavelength=wave_obs, name="predictive")

    wave_model = np.linspace(1000.0, 20000.0, 500)   # rest frame
    zred = 0.1
    spec.setup_for_model(wave_model, zred=zred)

    # A flat unit model spectrum must project to ~1 on every pixel
    # (pure linear interpolation of a constant).
    pred = spec.predict(jnp.ones(wave_model.size), wave_model)
    assert pred.shape == (wave_obs.size,)
    np.testing.assert_allclose(np.asarray(pred), 1.0, rtol=1e-6)

The constant spectrum is a limiting case with a known answer. The test checks both the output shape and the numerical invariant.
