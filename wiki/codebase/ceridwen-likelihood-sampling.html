Ceridwen: Likelihood and Sampling

This layer converts predictions into posterior density values and asks an external algorithm to explore them.

Per-observation likelihood

A diagonal Gaussian compares four aligned arrays:

data y, prediction mu, uncertainty sigma, boolean mask

An optional DiagonalNoiseModel modifies the variance. It can add model-scaled fractional calibration, data-scaled fractional error, or additive jitter (ceridwen/ceridwen/likelihood/noise_model.py:210-280). The calculation is at lines 283-365. Both active fitting notebooks use log_f_calib for model-scaled spectral calibration uncertainty.

ceridwen/ceridwen/likelihood/noise_model.py:324-350

# Start with observational variance.
var: Array = sigma_obs ** 2

# Model-anchored fractional calibration error: sigma = f_calib * |mu|.
# Gradient flows through mu -> var -> inv_var -> lnl cleanly.
if self.use_fractional:
    f_calib = jnp.exp(params["log_f_calib"])
    var = var + (f_calib * jnp.abs(mu)) ** 2

# Data-anchored fractional systematic floor: sigma = f_data * |y|.
# Scales with the *observed* flux, so the variance does not depend on
# theta (no Eddington-type bias).  The natural form for pure zero-point
# uncertainties.  Requires the observed data to be passed explicitly.
if self.use_data_fractional:
    if data is None:
        raise ValueError(
            "DiagonalNoiseModel(use_data_fractional=True) requires the "
            "observed data array; call compute(..., data=y)."
        )
    f_data = jnp.exp(params["log_f_data"])
    var = var + (f_data * jnp.abs(data)) ** 2

# Additive noise floor (jitter).
# Parameterised as log_jitter so sampling is unconstrained.
if self.use_jitter:
    jitter = jnp.exp(params["log_jitter"])
    var = var + jitter ** 2

Every enabled term adds a squared uncertainty to var. The distinction is what anchors it: model prediction, observed data, or an absolute jitter.

Multiple observations

MultiObservationLikelihood stores matching tuples of observation keys and likelihood objects (likelihood/likelihood.py:793-837). Its call loops over those static pairs and sums log-likelihoods (lines 840-872).

For the joint notebook:

Different modalities retain different units because residuals are divided by uncertainties in the same units before their scalar log-likelihoods are added.

ceridwen/ceridwen/likelihood/likelihood.py:866-872

lnl_total = jnp.zeros(())
aux: dict[str, LikelihoodOutput] = {}
for key, lhood in zip(self.keys, self.likelihoods):
    lnl_i, aux_i = lhood(y[key], mu[key], sigma_obs[key], mask[key], params)
    lnl_total    = lnl_total + lnl_i
    aux[key]     = aux_i
return lnl_total, aux

The same key selects data, prediction, uncertainty, and mask. Each modality returns one scalar contribution, and those scalars are summed.

Prior

SedModel.ln_prior loops over registered priors and sums prior.logpdf for each free parameter (model/model.py:408-447). Parameters absent from the prior dictionary contribute zero, so the model configuration must make that choice intentional.

Sampler boundary

run_sampler extracts static observation arrays, then builds two JIT functions:

  • loglike_fn(theta): predict and sum data likelihoods.
  • logprior_fn(theta): call model.ln_prior.

It delegates both plus model.theta_init to a SamplerAdapter (sampler/runner.py:275-366). Keeping the functions separate supports both MCMC and nested sampling.

ceridwen/ceridwen/sampler/runner.py:335-366

# ── Static data extracted once, before trace ──────────────────────────
_obs_dict    = model.obs_dict
_keys        = tuple(likelihood.keys)
_likelihoods = tuple(likelihood.likelihoods)
_static_data = {
    key: (
        _obs_dict[key].flux,
        _obs_dict[key].uncertainty,
        _obs_dict[key].mask,
    )
    for key in _keys
}

# ── Log-likelihood: sum over observations, no prior ───────────────────
@jax.jit
def loglike_fn(theta: dict[str, Array]) -> Array:
    predictions = model.predict(theta)
    lnl = jnp.zeros(())
    for key, lhood in zip(_keys, _likelihoods):
        y_k, sig_k, mask_k = _static_data[key]
        mu_k    = predictions[key]
        lnl_k, _ = lhood(y_k, mu_k, sig_k, mask_k, params=theta)
        lnl = lnl + lnl_k
    return lnl

# ── Log-prior ─────────────────────────────────────────────────────────
@jax.jit
def logprior_fn(theta: dict[str, Array]) -> Array:
    return model.ln_prior(theta)

# ── Delegate ──────────────────────────────────────────────────────────
return adapter.run(loglike_fn, logprior_fn, model.theta_init, rng_key)

Data are captured once outside the compiled closures. The adapter receives two functions plus an initial parameter tree; it does not need to know Ceridwen’s observation classes.

NUTS path

BlackJAXNUTSAdapter:

  1. Flattens the parameter dictionary (sampler/nuts.py:308-324).
  2. Maps bounded parameters to unconstrained coordinates.
  3. Adds the transformation Jacobian to the posterior (lines 395-422).
  4. Adapts step size and mass matrix during warmup (lines 426-468).
  5. Runs compiled NUTS chains (lines 470-530 onward).
  6. Reconstructs named posterior arrays in SamplingResult.

The unconstrained transformation prevents hard uniform boundaries from acting as geometric walls for Hamiltonian trajectories.

Nested-sampling path

BlackJAXNestedSamplerAdapter requires a proper prior for every free parameter. It draws the initial live ensemble directly from those priors (sampler/nested.py:156-190), then runs the BlackJAX nested slice sampler over separate likelihood and prior functions.

ceridwen/ceridwen/sampler/nested.py:341-355

rng_key, prior_key = jax.random.split(rng_key)
particles = self._sample_prior(theta_init, prior_key)

nested_sampler = blackjax.nss(
    logprior_fn      = logprior_fn,
    loglikelihood_fn = loglike_fn,
    num_delete       = num_delete,
    num_inner_steps  = num_inner_steps,
)
init_fn = jax.jit(nested_sampler.init)
step_fn = jax.jit(nested_sampler.step)

Completed dead points receive evidence and importance weights through anesthetic (sampler/nested.py:502-529). Those weights must be normalized or resampled before posterior percentiles, predictive draws, or derived SFHs.

Result

SamplingResult stores named posterior samples, log likelihoods, evidence when available, diagnostics, timing, and backend-specific raw output (sampler/runner.py:69-128). NUTS returns equal-weight posterior samples and no Bayesian evidence. Nested sampling returns weighted dead points plus evidence and its uncertainty; the active notebooks convert those points to deterministic equal-weight posterior draws before downstream summaries.

High-level fitSED

fitSED constructs default diagonal likelihoods, builds an adapter, calls run_sampler, and writes HDF5 plus a text log (fit.py:148-282). The project notebooks currently use the lower-level route to customize likelihoods.
