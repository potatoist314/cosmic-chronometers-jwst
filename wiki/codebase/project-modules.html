src/cosmology.py

This is a small early cosmology helper. No active notebook currently imports it.

  • E(z, omega_m) computes the flat matter-plus-dark-energy expansion factor (src/cosmology.py:5-8).
  • H(z, H0, omega_m) multiplies it by an Astropy quantity carrying units (src/cosmology.py:10-12).
  • age_integrand(z, omega_m) supplies the dimensionless integrand used by SciPy quadrature (src/cosmology.py:15-16).

The module ends at line 20 and imports quad without wrapping the full age integral. Treat it as a partial learning module, not a complete cosmology API.

src/cosmology.py:5-16

def E(z, omega_m):
    ''' Dimensionless hubble parameter, E(z) = H(z) / H (0) '''
    ''' Radiation neglible, curvature negligible, only matter and dark energy'''
    return np.sqrt(omega_m * (1+z)**3 + (1 - omega_m))

@u.quantity_input #@ calls a decorator, quantity_input is the astropy function
def H(z, H0: u.Quantity[u.km/u.s/u.Mpc], omega_m):
    return E(z, omega_m) * H0


def age_integrand(z, omega_m):
    return 1/((1+z)*E(z, omega_m))

H delegates the dimensionless calculation to E. age_integrand reuses E again; these calls reveal the module’s dependency direction.

This module extracts the expensive per-galaxy MCMC from notebook 02 so it can run safely in worker processes.

  • log_prob_factory creates a bounded vectorized likelihood closure (src/lick_inference.py:11-24).
  • fit_galaxy_arrays validates measurements, constructs the four-dimensional interpolator, broadens to effective sigma, runs emcee, and summarizes age, [Z/H], and [alpha/Fe] (lines 27-105).
  • initialize_fit_worker stores read-only grid arrays once per process (lines 108-133).
  • fit_galaxy_task turns one serializable task into a completed, skipped, or failed record (lines 136-166).

The worker-global _WORKER_STATE avoids repeatedly sending the large model grid with every task. The task itself contains only one galaxy’s arrays and metadata.

src/lick_inference.py:11-24

def log_prob_factory(interp, obs, err, sigma, lo, hi):
    """Return the vectorized Borghi et al. (2022a) Equation 7 likelihood."""

    def log_prob(theta):
        theta = np.atleast_2d(theta)
        inside = np.all((theta >= lo) & (theta <= hi), axis=1)
        out = np.full(len(theta), -np.inf)
        if inside.any():
            points = np.column_stack([theta[inside], np.full(inside.sum(), sigma)])
            chi2 = np.sum(((obs - interp(points)) / err) ** 2, axis=1)
            out[inside] = -0.5 * chi2
        return out

    return log_prob

Bounds are checked before interpolation. Invalid walkers keep -np.inf; valid walkers receive a Gaussian -chi2/2 score.

Data scripts

build_borghi2022_legac_dr2_subset.py is the central transformation script. Its main reads both catalogues, validates required columns, matches by object ID, checks coordinate separation, retains repeat spectra, applies the strict 215 km/s split, and writes joined and audit tables (lines 176-358).

download_legac_dr2_spectra.py is a resumable downloader. It validates the catalogue filename set (lines 47-61), validates each FITS structure (lines 64-79), downloads through a .part file and atomically renames it (lines 82-110), then verifies the complete set (lines 113-146).

download_cosmos2015_legac_dr2_photometry.py queries VizieR in batches, keeps the nearest match per LEGA-C row, adds object identifiers and match separation, and writes a FITS table (lines 61-125).
