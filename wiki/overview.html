Overview

This repository develops age-based cosmology analyses for massive quiescent galaxies. Notebooks provide the main interface. The src/ directory contains reusable calculations. The scripts/ directory prepares data. Ceridwen is a separate SED-fitting submodule.

Project flow

papers + raw catalogues
          |
          v
       scripts/  ---------->  data/processed/
          |                         |
          +-------------------------+
                                    v
                              notebooks/
                              /    |    \
                         milespy Prospector Ceridwen
                            |                 |
                            v                 v
                     src/lick_inference   ceridwen/

The project has two related inference paths:

  • Cosmic-chronometer notebooks use galaxy ages to constrain cosmology.
  • Stellar-population notebooks infer ages from indices, spectra, or photometry.
  • These notebooks use MILES, Prospector with FSPS, or Ceridwen.

Ceridwen flow

SSPData(Afe) -> CSPBasis(_afe) -> Observation objects -> SedModel
                                                        |
                                                        v
                                      likelihood -> sampler -> SamplingResult
  • The SSP grid supplies spectra for a range of ages and compositions.
  • The CSP combines the spectra with an SFH and a metallicity history.
  • Each observation projects one model spectrum into measured data space.
  • SedModel manages parameters, transforms, priors, and predictions.
  • The likelihood compares each prediction with the data.
  • An adapter runs the sampler.

Ceridwen exports

ceridwen/ceridwen/__init__.py:40-42

from .ssps import SSPData
from .csp import CSPBasis
from .model import SedModel

The package exports SSPData, CSPBasis, and SedModel in forward-model order.
