Overview

This repository develops age-based cosmology analyses for massive quiescent galaxies. Its primary interface is a sequence of notebooks; reusable numerical logic lives in src/, data preparation lives in scripts/, and Ceridwen is a separate SED-fitting submodule.

Project flow

papers + raw catalogues
          |
          v
       scripts/  ---------->  data/processed/
          |                         |
          +-------------------------+
                                    v
                              notebooks/
                              /    |    \
                         milespy Prospector Ceridwen
                            |                 |
                            v                 v
                     src/lick_inference   ceridwen/

The project has two related but distinct inference paths:

  • Cosmic-chronometer notebooks turn galaxy ages into cosmological constraints.
  • Stellar-population notebooks infer those ages from indices, spectra, or photometry using MILES, Prospector/FSPS, or Ceridwen.

Ceridwen flow

SSPData(Afe) -> CSPBasis(_afe) -> Observation objects -> SedModel
                                                        |
                                                        v
                                      likelihood -> sampler -> SamplingResult
  • The SSP grid supplies precomputed spectra over age and composition.
  • The CSP combines them according to an SFH and metallicity history.
  • Observations project one model spectrum into measured data space.
  • SedModel manages parameters, transforms, priors, and predictions.
  • The likelihood compares predictions with data; an adapter runs the sampler.

SSPData, CSPBasis, and SedModel are package-level exports in forward-model order.
