Notebook Map

Scope

Active root notebooks are the project’s scientific entry points. Practice notebooks live separately under notebooks/practice/. Saved outputs are evidence only when cell source, execution order, inputs, and kernel still match.

Ceridwen notebooks

ceridwen_test_spectra.ipynb fits one LEGA-C spectrum. It loads the local high-resolution Kroupa grid ceridwen/amist_c3k_hr_krou_afe.h5, performs wavelength/flux conversion, constructs Spectrum, adds calibration noise, and runs NUTS.

ceridwen_integrated_photometry_spectra.ipynb combines both observation types into one SedModel and one MultiObservationLikelihood. It also uses the local high-resolution Kroupa grid and anchors spectrum normalization to photometry before the joint posterior.

Practice

notebooks/practice/fits-viewer.ipynb contains one FITS-table inspection cell and is a viewer, not an analysis pipeline.

Kernels

  • notebooks/practice/fits-viewer.ipynb records the root Python 3.14 kernel.
  • The two Ceridwen notebooks record Python 3.11 kernels.

Kernel choice is part of each notebook’s executable contract.

Examples

notebooks/ceridwen_integrated_photometry_spectra.ipynb · “Joint posterior” · code cell 18

joint_likelihood = MultiObservationLikelihood(
    keys=(phot_obs.name, spectrum_obs.name),
    likelihoods=(
        DiagonalGaussianLikelihood(),
        DiagonalGaussianLikelihood(noise_model=DiagonalNoiseModel(use_fractional=True)),
    ),
)
joint_result = run_sampler(
    joint_model,
    joint_likelihood,
    joint_adapter,
    jax.random.PRNGKey(SEED),
)

The notebook assembles existing objects: two observation keys, two likelihoods, one model, and one sampler adapter. The inference algorithm itself lives in modules.
