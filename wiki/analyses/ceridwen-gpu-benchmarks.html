Speed and cost

  • The RTX 4090 was 2.33 times faster than the RTX 3090.
  • The H100 was 5.37 times faster than the RTX 3090.
  • The H100 was 2.31 times faster than the RTX 4090.
  • The A100 was 2.95 times faster than the V100.
  • The RTX 4090 offer had the lowest cost per call.
  • The cost result applies only to these three Vast offers.

GPU memory

Every GPU type used a similar amount of memory. The Ceridwen calculation peak stayed between 1,460 MiB and 1,610 MiB on all five GPU types.

Evidence: results/ceridwen_vast_v100_memory_verification_complete_2026-08-26/ and the benchmark records above

Modal A100 kernel trace

One kernel used 93.8% of the GPU event time. It ran 564 times inside one 7.843 s step. The GPU stream stayed active for 94.9% of that step. Matrix multiplication kernels used 0.047% of the GPU event time.

Project synthesis: The kernel is probably the weighted sum over the SSP grid. The model builds each spectrum with one einsum over metallicity, age, and wavelength (ceridwen/ceridwen/csp/csp_afe.py:1845).

Evidence: results/ceridwen_modal_a100_kernel_trace_complete_2026-08-26/
