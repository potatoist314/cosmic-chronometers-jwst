Ceridwen GPU benchmark

Matched Vast benchmark

This is a short throughput benchmark. It is not a complete posterior fit.

Each GPU used grid schema 2.1, 11 photometric bands, and 3,523 spectral pixels.

Each row contains five post-JIT steps. These steps made 5,000 likelihood calls.

The trace used the matched benchmark model, data, seed, and NSS settings. One warm-up step completed before tracing.

The GPU stayed active, but one XLA reduction fusion dominated its work. Host launch gaps and matrix multiplication were small.

Project synthesis: The main bottleneck is the large fused reduction, not GEMM throughput. FP64 tensor cores are unlikely to explain the 2.95-fold A100 advantage.

The timeline has no hardware instruction counters. It does not prove whether any kernel issued tensor-core instructions.
