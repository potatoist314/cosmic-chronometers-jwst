JAX runs Ceridwen calculations on the GPU. It reported the calculation peak, memory in use, and memory reserved for reuse.

NVML is NVIDIA's GPU monitor. It reported the whole process peak, including JAX and NVIDIA support software.

JAX did not reserve most GPU memory at startup. The two calculation peaks matched within 0.001%.
